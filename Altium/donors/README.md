# Altium Donors

The current compact schematic and project-descriptor seeds live in
[`../source_pack/donors/`](../source_pack/donors/) because they are runtime
catalogue evidence. This directory is reserved for future raw donor archives,
desktop-open evidence, and controlled source comparisons.

Future family or PCB donor work must capture the smallest native Altium project
that proves symbol, pin, value, footprint, pad, board, rule, or routing
behavior. Record source hashes and the exact desktop result. Do not store
generated output here; each generated candidate belongs in a unique experiment
run with its normalized input and validation report.
