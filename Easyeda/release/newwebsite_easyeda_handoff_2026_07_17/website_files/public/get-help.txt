# What is Progen EDA?

Progen EDA is an AI-powered circuit generation platform that converts natural-language prompts into structured circuit outputs. It is designed to help users describe a circuit in plain English and receive a more organized schematic or netlist generation result.

Instead of manually planning every component, placement, wire, and validation step, Progen follows an intelligent workflow that interprets your prompt, improves it, selects supported components, plans the arrangement, places components, generates wiring, validates the design, and prepares the final output.

Progen is built around a simple idea:

Prompt. Plan. Place. Wire. Validate. Output.

---

# How Progen EDA works

Progen EDA uses a multi-step circuit generation pipeline. This process helps the system move from a rough natural-language idea to a more structured, validated circuit output.

The workflow includes:

1. Prompt
   The user describes the circuit in natural language.

2. Prompt Enhancer
   The system improves and clarifies the user’s original prompt.

3. Enhanced Prompt to Script-Understandable Code
   The prompt is converted into a more structured format that the system can process.

4. Code Enhancer
   The internal circuit-generation instructions are improved for better accuracy.

5. Code Validator
   The system checks whether the generated instructions are complete and usable.

6. File Name Decider
   The system decides a suitable output file name for the generated circuit.

7. Arrangement Decider
   The system decides how the circuit should be organized visually.

8. Component Selector
   The system selects supported components based on the prompt.

9. Validator
   The selected components and structure are checked for correctness.

10. Component Placer
    The system places the selected components into the circuit layout.

11. Placement Validator
    The component placement is checked for spacing, logic, and output quality.

12. User Specification Validator
    The design is checked against the user’s original requirements.

13. Beautifier
    The circuit layout is cleaned and improved visually.

14. Beautifier Validator
    The beautified layout is checked again for quality.

15. Decision: Wire / Terminal / Combination
    The system decides whether the circuit should use wiring, terminals, or a combination of both.

16. Wiring Planner
    The system plans how the circuit connections should be routed.

17. Terminal Placer
    The system places terminals where needed.

18. Wiring Maker
    The system creates the actual wiring logic.

19. Value Editor
    The system adjusts or confirms component values.

20. Value Validator
    The component values are checked for correctness and consistency.

21. Final Validator
    The final circuit output is checked before completion.

22. Output
    The validated circuit result is produced for the user.

This workflow helps Progen EDA act like an intelligent circuit-generation assistant instead of a basic text-to-output tool.

# Writing better prompts

A good circuit prompt gives Progen enough information to understand what you want to build. The more specific your prompt is, the better the generated circuit output can be.

A strong prompt should include:

Circuit purpose
Input voltage
Output voltage
Required components
Preferred topology
Current requirement
Load type
Protection needs
Simulator or output target
Any special constraints

Weak prompt example:

Make a power supply.

Better prompt example:

Design a 24V to 5V isolated DC-DC converter with input protection, output filtering, and a regulated 5V output for a small embedded system.

Another strong prompt example:

Create a low-noise instrumentation amplifier for a small sensor signal using an op-amp. The circuit should include gain-setting components, input filtering, and a stable output stage.

Another strong prompt example:

Generate an active PFC power supply stage with protection components, validation checks, and a clean schematic arrangement.

Prompt formula:

Design a [circuit type] that takes [input condition] and produces [output condition] using [preferred components or topology]. Include [protection/filtering/validation requirements] and prepare the output for [target simulator or use case].

# Understanding generation results

After you submit a prompt, Progen EDA may return different types of results depending on the prompt quality, component support, and validation status.

Validated output means the circuit passed the core generation and validation checks.

Warning output means the circuit was generated, but some values, components, or assumptions may need manual review.

Failed generation means the system could not confidently create a valid circuit from the prompt.

Unsupported component means the prompt requested a component that is not currently available in the supported component library.

Validation failed means the generated design may have missing values, missing connections, unsupported topology, incorrect placement, unclear specifications, or design logic issues.

Proteus-ready output means the result has been prepared for a Proteus-oriented schematic or netlist workflow.

Always review important circuit outputs before using them in real hardware, assignments, simulations, or production work.

# Common generation problems

## Why did my circuit fail to generate?

Your prompt may be missing important information. Add the circuit purpose, input voltage, output voltage, required components, load requirement, and output target.

Instead of writing:

Create an amplifier.

Write:

Create a non-inverting op-amp amplifier using LM741 with a gain of 10, powered by a dual supply, with input and output labels.

---

## Why is my output not accurate?

AI-generated circuit outputs depend heavily on the prompt. If your prompt is vague, the system may make assumptions. Try adding exact component values, voltage levels, circuit type, and constraints.

---

## Why is a component missing?

The component may not be supported yet. Check the Supported Components page. If the component is not listed, request additional component support.

---

## Why did validation fail?

Validation may fail because of missing connections, unsupported topology, incomplete values, unclear requirements, or incompatible component choices.

Try simplifying the prompt or adding more exact information.

---

## Why did the circuit use a different component?

If the requested component is unsupported, Progen may use a supported alternative. For best results, use components from the supported component list.

---

## Can I use Progen EDA with Proteus?

Yes. Progen EDA is designed around schematic and netlist generation workflows that can support Proteus-based circuit creation.

---

## Are AI-generated circuit outputs always correct?

No. AI outputs may contain mistakes. Always verify critical results, electrical safety, component ratings, values, and connections before using the circuit practically.

# API key safety

Progen EDA may allow users to connect or manage API keys depending on the selected workflow. API keys should always be handled carefully.

Important API key safety rules:

Never share your API key publicly.
Never paste API keys into screenshots.
Never expose API keys in frontend code.
Use environment variables where possible.
Rotate keys if you think they were exposed.
Delete unused keys.
Use restricted permissions where available.
Do not store keys in plain text.
Do not share keys with other users.

If you believe your API key was exposed, revoke it immediately and create a new one.

When requesting a component, include:

Component type
Common symbol name
Package or model if needed
Use case
Why the component is required

Example request:

Please add support for the IRF540N MOSFET. I need it for DC motor driver and switching power supply circuits.

# FAQ

## What is Progen EDA?

Progen EDA is an AI-powered electronic design automation platform that helps turn natural-language prompts into structured, validated circuit outputs.

## How do I write a good prompt?

A good prompt should include circuit purpose, input voltage, output voltage, required components, load requirement, design constraints, and output target.

## What components are supported?

Progen supports sources, passives, diodes, LEDs, transistors, MOSFETs, analog ICs, logic ICs, protection components, utility components, and display components.

## Can Progen generate Proteus-ready circuits?

Progen is designed to support schematic and netlist generation workflows that can be used with Proteus-oriented circuit design processes.

## Why did my circuit fail?

Your circuit may fail if the prompt is unclear, values are missing, requested components are unsupported, or validation detects incomplete design logic.

## Can I request a new component?

Yes. Use the Request Component option and include the component name, type, use case, and reason for needing it.

## Are Progen outputs always correct?

No. AI-generated outputs can contain errors. Always verify important circuit results before using them in real hardware or serious simulations.

## What does validation mean?

Validation means the system checks the generated circuit for completeness, supported components, placement quality, wiring logic, values, and user requirements.

## What should I do if validation fails?

Review the error, improve your prompt, use supported components, add missing values, and regenerate the circuit.

## Is Progen useful for students?

Yes. Progen can help students understand circuit structure, component selection, schematic planning, and validation workflows.
