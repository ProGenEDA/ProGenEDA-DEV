# IC Pairwise 34 V1 Diagnostics

Date: 2026-06-10

## Purpose

This pack starts the all-pairs mixing pass requested after exact-rezip testing.
It creates every unordered pair from 34 IC-only exact-rezip source cases.

This is experimental and is not main-generator support yet.

## Source Set

The raw exact-rezip pack now has 41 cases. The pairwise source set intentionally
uses 34:

- excludes old `T018_74HC4060_REPO_SINGLE_EXACT_REZIP`, rejected by user test;
- excludes old `T020_74HC4520_EXACT_REZIP`, rejected by user test;
- excludes `T037_74HC4060_REFRESH_4X_RLC_EXACT_REZIP` because this matrix is
  IC-only;
- excludes refreshed 4520 `T038` through `T041` until the exact-rezip probes
  pass in Proteus.

The refreshed 4060 IC-only controls `T034`, `T035`, and `T036` stay in the
matrix because user testing reported `T034` onward worked.

## Method

Each pair project:

- concatenates complete donor object chunks;
- remaps only the right-hand donor package refs using same-length `U` refs;
- preserves subpart suffixes such as `U1:A`;
- rebuilds `ROOT.CDB` with a generic CDB splitter that supports multiple
  subpart pin rows sharing one package property row;
- preserves full donor device sections and patches section tail pointers;
- translates the right-hand donor terminal, wire, and known body coordinate
  fields to reduce overlap.

No arbitrary new IC records are synthesized.
