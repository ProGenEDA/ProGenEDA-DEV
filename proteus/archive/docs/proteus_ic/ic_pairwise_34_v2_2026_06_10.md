# IC Pairwise 34 V2 Diagnostics

Date: 2026-06-10

## Purpose

This pack regenerates all 561 unordered pairs from the 34 IC-only exact-rezip
source cases after user testing of V1 exposed three repeatable failure classes:

- many early subpart/package pairs opened but failed simulation with duplicate
  part references such as `U2:A [U1:A]` and duplicate `X000000..` internal refs;
- pairings involving `7447`/`74HC47` could open but reported no model specified
  for `U2`;
- pairs involving refreshed `74HC4060` sources `S32`, `S33`, and `S34`
  simulated, but the terminals moved far away from their IC bodies and labels,
  creating long visual wires.

V2 is still a temporary diagnostic pack, not main-generator support.

## Source Set

The source set is unchanged from V1:

- 34 IC-only exact-rezip source cases;
- old rejected `T018_74HC4060_REPO_SINGLE_EXACT_REZIP` excluded;
- old rejected `T020_74HC4520_EXACT_REZIP` excluded;
- RLC-containing `T037_74HC4060_REFRESH_4X_RLC_EXACT_REZIP` excluded;
- refreshed 4520 `T038` through `T041` excluded until exact-rezip testing
  passes.

## V2 Changes

- `ROOT.CDB` is split by pin rows first, then property rows are parsed against
  the ordered unique package refs. This supports subpart rows such as
  `U1:A..U1:D` with one package property row `U1`.
- When donor-final property rows are concatenated before another donor's
  property section, the donor-final row is trimmed by four bytes so the next
  property row boundary remains valid.
- Body-coordinate translation now includes short visible body markers `4060`
  and `4520` in addition to full component names.
- Component ID, component value, and subckt-name text coordinate records are
  moved with the translated donor chunk.
