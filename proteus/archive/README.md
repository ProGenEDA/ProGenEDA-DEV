# Proteus Archive Index

This archive preserves Proteus material that is not needed by the current
runtime/test closure. Historical files are kept unchanged; this index adds
location context without rewriting their claims, commands, or original paths.

## Contents

- `docs/` — historical specs, plans, handoffs, reports, donor-learning notes,
  and recovered documentation.
- `knowledge/` — superseded question/rule/source snapshots that remain useful
  for provenance.
- `donors/` — donor-learning bundles outside the active runtime/test closure.
- `backups/` — timestamped working-script and project backups.
- `legacy_entrypoints/` — superseded Python/shell entrypoints retained for
  history, never as current terminal workflows.
- `recovered_artifacts/` — migrated/recovered projects and packages.
- `historical_examples/` — old output and example material.

For current implementation and commands, start at
[`../active/README.md`](../active/README.md). For dated evidence, use
[`../experiments`](../experiments).
