# Terminal Placer Bidir Probe V2

These cases use the accepted component placer first, then append donor-derived `$TERBIDIR` records.
V2 covers every selected user component family in the case, not only passives.
No Proteus wire records are emitted yet; this is a side-anchor probe, not final wire-backed pin attachment.
Inspect whether left-side terminals are 180-degree bidirs and right-side terminals are 0-degree bidirs.
D20/display sentinel infrastructure is intentionally skipped because it is not a user-requested component pin.
The labels are generated by this stage so future wiring/naming work stays in one owner.
