# Manual terminal donor: current FET/BJT group

This project was generated from the locked mega donor using the shared component placer and shared terminal placer.

Already terminalized (do not edit their terminal behavior):

- all 20 accepted two-pin families
- POT-HG, LM317T, OPAMP

Intentionally unterminalized: add one short WIRE-attached terminal to every visible pin, then return the saved `.pdsprj` as authoritative donor evidence.

- NMOSFET
- 2N7000
- BS170
- NPN
- PNP
- 2N3904
- 2N4401

Use grid-aligned terminal contacts; left-side terminals at 180 degrees and right-side terminals at 0 degrees. Do not move the already terminalized components or their records.
