# LTspice Generated Evidence

Every executable invocation creates a new immutable timestamped run directory
here when `--outdir ltspice/examples` is used. Do not overwrite or edit a prior
run. The default donor-native engine records the resolved stock-symbol
catalogue, placement, physical wire plan, temporary live catalogue, native ASC
recipe, and post-write parse validation. The historical prototype may also
record optional external oracle results.

An invocation's static result is candidate evidence, not automatic GUI
acceptance. A fixture becomes donor-native release evidence only after it has
been opened in LTspice, screenshot-assessed, and recorded against the
placement/property/mixed-wire matrix in
[../docs/SUPPORT_GAPS.md](../docs/SUPPORT_GAPS.md). The donor-native run
contains no custom ASY, generated model library, named terminal, or named-net
label fallback.

The local all-observed-family GUI smoke run is documented in
[../docs/NATIVE_GUI_VERIFICATION.md](../docs/NATIVE_GUI_VERIFICATION.md).

The repository's tests generate temporary fixtures rather than committing
machine-specific `.raw` data or proprietary executable output.
