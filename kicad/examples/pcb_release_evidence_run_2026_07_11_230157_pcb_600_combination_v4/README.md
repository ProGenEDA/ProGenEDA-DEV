# PCB Release Evidence Run

Final KiCad 10.0.4 fabrication and visual evidence for five accepted boards from `progen_kicad_executable_run_2026_07_11_174321_pcb_600_combination_v4`.

Boards: MJ001, MJ002, N01, N02, and N20.

Each board folder contains:

- eight Gerber/job files for two copper layers, masks, silkscreens, and board outline,
- Excellon drill output plus drill report,
- component position CSV,
- schematic BOM CSV, and
- top-side KiCad 3D render.

All five boards are also included in the 495/495 passing KiCad DRC oracle run `pcb_cli_oracle_run_2026_07_11_185217_pcb_600_combination_v4`.
